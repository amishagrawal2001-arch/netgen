# Documentation Directory

This directory contains all project documentation and README files.

## Organization

- **Main README**: The primary `README.md` file remains in the project root for easy access.
- **All other documentation**: All additional README files, guides, and documentation are stored in this directory.

## Adding New Documentation

When creating new documentation files:
1. Place them in this `README_ALL/` directory
2. Use descriptive filenames (e.g., `FEATURE_NAME_GUIDE.md`, `COMPONENT_README.md`)
3. Update this file if needed to maintain organization

## Current Documentation

This directory currently contains:
- DPDK integration guides
- Installation and configuration guides
- Architecture and design documents
- Troubleshooting guides
- Feature-specific documentation

## Naming Convention

- Use UPPERCASE for main topics: `FEATURE_NAME.md`
- Use descriptive names: `COMPONENT_PURPOSE.md`
- Include version or date if needed: `FEATURE_v2_GUIDE.md`
