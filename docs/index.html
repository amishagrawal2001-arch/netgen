Built for the lab.

Everything you need to characterize a network device, all in one open binary.

⚡

DPDK tx_worker

Multi-queue per-stream sender on commodity NICs. Mellanox mlx5, Intel ice / i40e, Broadcom bnxt. Up to 16 TX cores per stream with automatic core picking based on link speed and frame size.

📊

RFC 2544 throughput

Classic IETF §26.1 binary search per frame size. 64B → 1518B across the standard IETF set. Cooperative stop, live progress polling, CSV export for customer reports.

⏱️

One-way latency

NLAT header timestamps in each UDP payload. RX-side scapy sampler computes min / avg / p50 / p99 / max over a rolling 10K-sample window. Sub-microsecond resolution on loopback.

📈

Live throughput chart

Rolling 60-second per-interface bit-rate plot, pure-QPainter (no matplotlib). Auto-scales Y from kbps to Gbps. One line per interface, color-coded legend, no extra deps.

🎯

Per-flow randomization

Spirent/Ixia-style "modifiers" — cycle src/dst IP and L4 ports across configurable ranges for 5-tuple-hash distribution. RSS and LAG balancing testing without a hardware tester.

📦

PCAP replay

Upload any capture, replay it at line rate or controlled pps. Streaming uploader handles 100+ MB captures without freezing the UI. Loop, rate-shape, or single-pass.

Three commands to first packet.

One installer brings DPDK + Mellanox drivers + tx_worker + server. The client is a single Python module.

1

Install on the server

Apt-retry hardened against flaky mirrors; pulls DPDK 23.11, mlx5 PMD, hugepages config, and the netgen Flask server.

2

Start the client

PyQt5 GUI connects to the server, discovers interfaces, and renders the streams table with live stats polling.

3

Add a stream and hit Start

Right-click an interface, configure the stream, optionally tick "Enable DPDK" and "Enable timestamps" — done.

# On the server (Ubuntu 22.04+)
sudo python3 install_ostg_complete.py

# Launch the server
sudo netgen-server --port 5050

# On your laptop
git clone https://github.com/DAY-Advisor/NetGenI.git
cd NetGenI
pip install -r requirements.txt
python3 -m traffic_client \
    --server http://<your-server>:5050

Two-process, REST-glued.

A Flask server runs on the box that owns the NICs. The PyQt5 client runs anywhere — your laptop, a CI runner, a Docker container.

netgen-server

Flask DPDK 23.11 SQLite scapy
  • tx_worker C process per stream (DPDK), multi-queue
  • Scapy fallback for non-UDP (ICMP, TCP, custom)
  • Stream database (SQLite) + tracker thread for per-flow stats
  • Per-iface latency sampler via libpcap
  • RFC 2544 runner thread with cooperative cancel
  • Single-page /admin web UI

traffic_client (GUI)

PyQt5 QThread QPainter
  • Stream editor, copy/paste, inline editing
  • Live stats dock with per-interface + per-stream tabs
  • Rolling throughput chart (60s window)
  • RFC 2544 wizard with CSV export
  • Background workers + local event loops keep the UI responsive
  • Help → Install Guide + API Guide embedded

Scriptable from anywhere.

Every action the GUI takes is a REST call. Use the same endpoints from your CI pipeline, your monitoring system, or your shell.

# Start a UDP stream at line rate via DPDK
curl -X POST http://<server>:5050/api/traffic/start \
  -H "Content-Type: application/json" \
  -d '{
    "streams": {
      "Port:enp181s0f0np0": [{
        "name":          "udp-blast",
        "enabled":       true,
        "L3":            "IPv4",
        "L4":            "UDP",
        "frame_size":    64,
        "stream_rate_type": "Line Rate",
        "dpdk_enable":   true,
        "dpdk_tx_cores": 4,
        "enable_timestamps": true,
        "protocol_data": {
          "mac":  {"mac_source_address": "aa:bb:cc:dd:ee:01",
                   "mac_destination_address": "aa:bb:cc:dd:ee:02"},
          "ipv4": {"ipv4_source": "10.0.0.1",
                   "ipv4_destination": "10.0.0.2"},
          "udp":  {"udp_source_port": "1234",
                   "udp_destination_port": "4791"}
        }
      }]
    }
  }'

# Poll latency stats on the RX side
curl 'http://<server>:5050/api/latency/stats?iface=enp181s0f1np1'

# Kick off an RFC 2544 throughput test
curl -X POST http://<server>:5050/api/rfc2544/start \
  -H "Content-Type: application/json" \
  -d '{"tx_iface":"enp181s0f0np0", "rx_iface":"enp181s0f1np1",
       "frame_sizes":[64,512,1518], "duration_per_step":10,
       "mac_src":"aa:bb:cc:dd:ee:01","mac_dst":"aa:bb:cc:dd:ee:02",
       "ip_src":"10.0.0.1","ip_dst":"10.0.0.2"}'

Full reference: Help → API Guide in the GUI, or see API_GUIDE.md in the repo.
